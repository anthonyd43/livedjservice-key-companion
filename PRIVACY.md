# Privacy Policy — LDS Key Companion

**Last updated: 19 August 2026**

## Summary

LDS Key Companion does not collect, store, transmit, or sell any data.

## What the extension does

The extension runs only on livedjservice.com. On that site it reads the Camelot
key codes already displayed in track listings (for example `8A`) and displays
the equivalent musical key beside each one (`8A / Am`). The translation is done
locally using a fixed lookup table built into the extension.

## Data collection

None. Specifically, the extension does not collect or process:

- Personally identifiable information (name, address, email, age, ID numbers)
- Health information
- Financial or payment information
- Authentication information (passwords, credentials, security questions)
- Personal communications (email, texts, chat messages)
- Location data
- Web history or browsing activity
- User activity (clicks, mouse position, scroll, keystrokes)
- Website content beyond the Camelot codes it reads on-screen to translate them,
  which are never stored or transmitted

## Data transmission

None. The extension makes no network requests of any kind. It contains no
analytics, no telemetry, no tracking, no external scripts, and no remote code.
Nothing leaves your browser.

## Data storage

None. The extension does not use browser storage, cookies, or any other
persistence mechanism. It holds no state between page loads.

## Permissions

The extension requests no permissions beyond running a content script on
livedjservice.com, which is required to read the Camelot codes on the page in
order to annotate them.

## Third parties

No data is shared with third parties, because no data is collected. The
extension is not affiliated with, endorsed by, or sponsored by
LiveDJService.com.

## Verification

The complete source code is public and can be reviewed at
https://github.com/anthonyd43/livedjservice-key-companion — every claim above
can be verified by reading it.
